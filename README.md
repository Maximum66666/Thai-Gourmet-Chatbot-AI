# Thai Gourmet AI & ThaiLLM Chatbot Dual Services

เว็บแอปพลิเคชันให้บริการปัญญาประดิษฐ์ (AI) 2 ระบบในแพลตฟอร์มเดียว:
1. **บริการที่ 1 (Food Recognition & Safety)**: วิเคราะห์และรู้จำภาพอาหารไทยด้วย Deep Learning ผ่าน **AI For Thai** พร้อมระบบประเมินความปลอดภัยสารก่อภูมิแพ้และข้อจำกัดทางโภชนาการเฉพาะบุคคล
2. **บริการที่ 2 (ThaiLLM AI Chatbot)**: แชทบอทอัจฉริยะภาษาไทยเชื่อมต่อ **ThaiLLM API** ด้วยโมเดล `pathumma-thaillm-qwen3-8b-think-3.0.0` รองรับการคิดวิเคราะห์ (Reasoning Process) การถาม-ตอบทั่วไป สูตรอาหาร และโภชนาการ

```
└── README.md
```

## 🚀 ข้อมูลการเชื่อมต่อ ThaiLLM (บริการที่ 2)

**Endpoint:**
```
POST http://thaillm.or.th/api/v1/chat/completions
```

**ตัวอย่าง cURL Request:**
```bash
curl http://thaillm.or.th/api/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <YOUR_THAILLM_BEARER_TOKEN>" \
  -d '{
    "model": "pathumma-thaillm-qwen3-8b-think-3.0.0",
    "messages": [
      {"role": "user", "content": "สวัสดี"}
    ],
    "max_tokens": 2048,
    "temperature": 0.3
  }'
```

## 🛠️ วิธีการติดตั้งและรันโปรเจกต์

1. **ติดตั้งไลบรารีที่จำเป็น:**
   ```bash
   pip install -r requirements.txt
   ```

2. **(ทางเลือก) กำหนดค่า Environment Variables:**
   ```bash
   # Windows PowerShell
   $env:THAILLM_API_KEY="your-actual-thaillm-token"
   $env:AIFORTHAI_API_KEY="your-aiforthai-key"

   # Windows CMD
   set THAILLM_API_KEY=your-actual-thaillm-token
   set AIFORTHAI_API_KEY=your-aiforthai-key
   ```
   *(หมายเหตุ: สามารถกรอกหรือเปลี่ยนคีย์ผ่านหน้าต่างตั้งค่าบนหน้าเว็บได้ทันที)*

3. **สั่งรันเซิร์ฟเวอร์:**
   ```bash
   python app.py
   ```

4. **เปิดเว็บเบราว์เซอร์:**
   ไปที่ [http://127.0.0.1:5000](http://127.0.0.1:5000)

## 🌟 ฟีเจอร์เด่น

### บริการที่ 1: ตรวจสอบอาหารไทย & สุขภาพ (Redesigned UI)
- **ดีไซน์ระดับพรีเมียม (Modern Glassmorphic UI)**: ปรับปรุงส่วนต่อประสานผู้ใช้ให้สวยงาม ทันสมัย แฝงความนุ่มนวล พร้อมการจัดกลุ่มและลำดับขั้นตอน (Step 1, 2, 3, Results) ชัดเจน
- **ทดสอบด่วนด้วยเมนูตัวอย่าง (Quick Test Samples)**: มีปุ่มเมนูยอดนิยม 5 เมนู (ต้มยำกุ้ง, ผัดไทย, ส้มตำ, แกงเขียวหวาน, ข้าวเหนียวมะม่วง) พร้อมภาพจำลองความละเอียดสูง กดปุ่มเดียวทดสอบระบบได้ทันทีโดยไม่ต้องค้นหาไฟล์ในเครื่อง
- **รองรับการป้อนภาพหลายรูปแบบ**: ลากและวาง (Drag & Drop), อัปโหลดจากโฟลเดอร์, ถ่ายภาพจากกล้องสมาร์ตโฟน/เว็บแคม, และวางรูปจากคลิปบอร์ดได้ทันทีด้วยคีย์ลัด **Ctrl + V**
- **พรีวิวภาพพร้อมฟังก์ชันขยาย (Lightbox Zoom)**: ตรวจสอบขนาดและรายละเอียดไฟล์ภาพ พร้อมปุ่มขยายดูภาพแบบเต็มหน้าจอ (Zoom Preview)
- **โปรไฟล์สุขภาพสำเร็จรูป (1-Click Health Presets)**: เลือกระดับความเสี่ยงด้วยคลิกเดียว เช่น แพ้อาหารทะเล, เบาหวาน, ความดัน/ลดเค็ม, กรดไหลย้อน, มังสวิรัติ หรือฮาลาล
- **ตัวชี้วัดความปลอดภัยสุขภาพ (Safety Shield Banner)**: แสดงผลสถานะความปลอดภัยด้วยสีและสัญลักษณ์ชัดเจน (ปลอดภัย / ควรระวัง / เสี่ยงอันตราย) พร้อมระบุสาเหตุ
- **แถบประเมินโภชนาการเด่น (Nutritional Snapshot)**: แสดงค่าประมาณการพลังงาน (Calories), โปรตีน, คาร์โบไฮเดรต และโซเดียมของเมนูที่ตรวจพบ
- **ตรวจสอบทางเลือกสำรองได้ทันที**: รายการเมนูอันดับรองสามารถกด *"ตรวจเมนูนี้"* เพื่อวิเคราะห์ความปลอดภัยซ้ำได้ทันทีโดยไม่ต้องอัปโหลดใหม่
- **คัดลอกสรุปผลลัพธ์ (Copy Summary)**: คัดลอกสรุปการตรวจอาหารและข้อมูลสุขภาพไปใช้งานต่อได้ง่ายดายในคลิกเดียว

### บริการที่ 2: ThaiLLM AI Chatbot
- **สลับบริการสะดวก (Dual Service Tabs)**: สลับระหว่างระบบรู้จำอาหารไทย และระบบแชทบอท ThaiLLM ได้ในคลิกเดียว
- **เชื่อมโยงผลลัพธ์อัตโนมัติ (Cross-Service Integration)**: เมื่อวิเคราะห์ภาพอาหารจากบริการที่ 1 สามารถกดปุ่ม *"ปรึกษาแชทบอท ThaiLLM เกี่ยวกับเมนูนี้"* เพื่อส่งต่อชื่อเมนูไปสอบถามรายละเอียด โภชนาการ หรือวิธีปรุงกับโมเดลภาษาได้ทันที
- **รองรับ Thinking Process**: แสดงผลกระบวนการคิดและวิเคราะห์ `<think>` ของโมเดล `pathumma-thaillm-qwen3-8b-think-3.0.0` ในรูปแบบกล่องพับเก็บได้
- **ปรับแต่งพารามิเตอร์ได้อิสระ**: รองรับการเปลี่ยน Model, Temperature (0.0 - 1.0), Max Tokens (256 - 8192) และ Bearer Token ได้ตามต้องการ
